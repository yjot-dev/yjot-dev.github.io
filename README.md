# Portafolio web de YJOT-DEV

Bienvenid@ a este repositorio. Este proyecto consiste en un portafolio web personal elaborado para presentar mi perfil profesional como desarrollador Android y Full Stack, junto con mis aplicaciones, proyectos, servicios y habilidades técnicas.

## ¿Qué es este proyecto?

Este sitio web funciona como una vitrina digital de mi experiencia profesional. Su objetivo es mostrar de forma clara y profesional:

- Mi perfil y trayectoria como desarrollador
- Los proyectos móviles que he desarrollado
- Los servicios que ofrezco
- Mis tecnologías y herramientas favoritas
- Un punto de contacto para clientes, reclutadores o colaboradores

## Características principales

- Diseño moderno y responsive
- Sección de presentación personal y experiencia
- Páginas dedicadas a proyectos y servicios
- Estructura organizada y fácil de mantener
- Uso de plantillas reutilizables para mejorar la escalabilidad del proyecto
- Preparado para publicarse en GitHub Pages

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js para la automatización de construcción de páginas
- GitHub Pages para el despliegue

## Stack técnico y enfoque profesional

Además de la web, este portafolio está alineado con mi perfil como desarrollador Android, destacando tecnologías como:

- Kotlin
- Jetpack Compose
- MVVM
- Clean Architecture
- Hilt
- MySQL
- Node.js
- Pruebas unitarias e instrumentales
- Integración de IA en flujos de desarrollo

## Estructura del proyecto

```text
assets/        # Imágenes, iconos y recursos visuales
css/            # Estilos del sitio web
js/             # Lógica de interacción del frontend
src/            # Páginas del portafolio y vistas de proyectos
templates/      # Plantillas reutilizables (header y footer)
index.html      # Página principal del sitio
```

## Requisitos previos

Para visualizar o modificar este proyecto necesitas:

- Un navegador moderno
- Git

## Buenas prácticas aplicadas

Este proyecto sigue principios recomendados en desarrollo de software, entre ellos:

- Separación clara entre contenido, estilos y lógica
- Estructura modular y mantenible
- Reutilización de componentes mediante plantillas
- Documentación básica para facilitar la colaboración y el mantenimiento
- Automatización de tareas de construcción para reducir errores manuales
