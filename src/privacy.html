POLÍTICA DE PRIVACIDAD

Última actualización

Fecha: 27/03/2026

Esta política de privacidad describe cómo se recopila, utiliza y protege la información de los usuarios en las aplicaciones desarrolladas por YJOT-DEV.

Información que recopilamos

Dependiendo de la funcionalidad de cada aplicación, podemos recopilar:

  • Información personal: Nombre, correo electrónico o número de teléfono, solo si el usuario la proporciona voluntariamente.
  • Datos de uso: Tipo de dispositivo, sistema operativo, duración de uso, funciones utilizadas dentro de la app.
  • Ubicación: Si la aplicación requiere servicios basados en ubicación, se solicitará permiso explícito.
  • Cámara: Si la aplicación requiere tomar fotografías o videos, se solicitará permiso explícito y el acceso se limitará al uso dentro de la app, sin almacenamiento externo ni compartición con terceros.
  • Galería: Si la aplicación requiere seleccionar imágenes o archivos multimedia desde la galería del dispositivo, se solicitará permiso explícito y el acceso será únicamente de lectura, sin modificar ni eliminar contenido.
  • Almacenamiento interno: Si la aplicación requiere acceder a archivos internos, se solicitará permiso explícito y el acceso será únicamente de lectura, sin alterar ni compartir los archivos.
  • API de Gmail: Algunas aplicaciones utilizan la API de Gmail de Google exclusivamente para enviar correos electrónicos transaccionales desde nuestra propia cuenta hacia los usuarios, ademas el único permiso solicitado a través de esta API es gmail.send, destinado exclusivamente al envío de correos electrónicos transaccionales. No se accede, almacena ni comparte información de las cuentas de correo de los usuarios.
  • APIs de Geocoding y Maps: Algunas aplicaciones utilizan servicios de Google Maps y Geocoding únicamente para mostrar mapas, calcular ubicaciones o rutas, sin almacenar ni compartir datos de ubicación con terceros.
  • Información de terceros: Nuestras aplicaciones pueden interactuar con servicios externos como Google Cloud, con el fin de usar sus APIs como: Gmail, Maps y Geocoding en nuestras apps para mejorar sus funcionalidades, ademas se usan servicios como: Cloud Run y Cloud Build para alojar y desplegar nuestras APIs remotas. Ademas en algunos proyectos se podria usar AdMob para mostrar publicidad. Otro servicio externo que utilizamos es Aiven como servidor de nuestras bases de datos MySQL. Cada uno de estos servicios puede recopilar información de acuerdo con sus propias políticas de privacidad.

Cómo usamos la información

La información recopilada se utiliza para:

  • Mejorar la experiencia del usuario.
  • Analizar el rendimiento y uso de la aplicación.
  • Enviar notificaciones (solo si el usuario lo permite).
  • Mostrar publicidad personalizada (si aplica).

Compartir información

No compartimos información personal con terceros, excepto en los siguientes casos:

  • Con proveedores de servicios que nos ayudan a operar la app(análisis, publicidad).
  • Cuando sea requerido por ley.

Privacidad de menores

Algunas de nuestras aplicaciones están dirigidas a menores de edad con fines educativos y didácticos. Estas aplicaciones recopilan únicamente información básica de perfil, como nombre de usuario y una imagen de perfil, sin solicitar ni almacenar datos sensibles (como audio, video, ubicación precisa o información de contacto). La información se utiliza exclusivamente dentro de la aplicación para personalizar la experiencia de aprendizaje y no se comparte con terceros. De ser el caso se solicita el consentimiento de los padres o tutores cuando sea requerido por la normativa aplicable. Si se detecta la recopilación de información adicional sin el consentimiento correspondiente, esta será eliminada de inmediato.

Derechos del usuario

Los usuarios tienen derecho a:

  • Solicitar acceso, corrección o eliminación de sus datos personales, para ello debe informarlo con un mensaje a esta dirección de correo electrónico: emprendimiento2020g7h2@gmail.com
  • Revocar permisos desde la configuración de su dispositivo móvil.
  • Eliminar su cuenta desde la aplicación.

Cambios en esta política

Nos reservamos el derecho de modificar esta Política de Privacidad en cualquier momento. Se notificará a los usuarios mediante la appo nuestra página web.
